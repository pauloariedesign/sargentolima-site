# sargentolima.com.br

Site de campanha — **Sargento Lima 2212 · Deputado Federal (PL/SC)**.
Site estático (HTML/CSS/JS puro). Publicação automática via Vercel a cada push na branch `main`.

## Páginas
- `index.html` — home (identidade da campanha)
- `emendas.html` — prestação de contas / mapa de emendas
- `moldura.html` — gerador de foto de perfil com a moldura da campanha
- `privacidade.html` — política de privacidade (LGPD)

## Deploy
Conectado ao Vercel (Git). Qualquer commit em `main` publica em produção.
